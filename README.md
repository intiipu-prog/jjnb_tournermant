# 진주 놀방 대진표 (JJNB MINI 4WD TOURNAMENT MANAGE)

진주 놀방 미니카 대회 운영용 대진표 웹앱입니다.

## 기능
- 선수 명단 관리 (이름·닉네임·소속·메모, 텍스트/엑셀/CSV 입력)
- 토너먼트: 2~5라운드, 예선·패자부활전·본선(3인/2인 1조), 결승라운드(순위결정전·최종결승)
- 포인트전: 1:1 리그 매트릭스(승2·패1·실격0) → 하위부터 서바이벌 → 결승
- 대회 결과·명예의 전당, 대회 수정/취소/삭제
- QR 공유(관람모드), 밴드·카카오톡 오픈채팅 QR

## 파일
- `index.html` — 앱 전체 (단일 파일)
- `data/players.json` — 선수 명단 백업 (54명, 2026-11-23)
- `data/tournament_results.csv` — 대회 결과 백업 (종료·취소 32건, 2026-11-23)
  - 앱의 [대회 결과 → ⬆ 결과 가져오기]로 그대로 불러올 수 있습니다 (입상 기록으로 복원).
  - 진행 예정 대회(11월 2차 M3·M2B)는 결과가 없어 제외했습니다.
  - 조별 대진 상세까지 백업하려면 앱의 [⬇ 결과 내보내기] 엑셀 파일을 `data/`에 올려 주세요.
